## 📖 Overview

This is my personal developer portfolio — built to showcase 12+ years of native Android engineering experience (Kotlin, Jetpack Compose, Clean Architecture, Firebase) alongside my transition into fullstack web development with **Next.js, React, tRPC, Drizzle ORM,** and **PostgreSQL**.

The site itself is a demonstration piece: a fast, animated, type-safe single-page application built with a modern Vite + React 19 + TypeScript stack, styled with Tailwind CSS v4 and animated with Framer Motion.

## ✨ Features

- ⚡ **Blazing fast** — Vite 7 build pipeline with instant HMR
- 🎨 **Modern UI/UX** — Tailwind CSS v4 utility-first styling with smooth Framer Motion transitions
- 🧭 **Client-side routing** — React Router v7
- 🔒 **Type-safe** — Strict TypeScript across the entire codebase
- 📱 **Fully responsive** — Mobile-first layout, tested across breakpoints
- 🧹 **Linted & consistent** — ESLint 9 flat config with React Hooks + Refresh rules
- 🌐 **Deployed on Vercel** — Zero-config CI/CD from `main`

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) ≥ 18
- npm (bundled with Node) or your preferred package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/Dev-moe-kyawaung/moekyawaung-developer-portfolio-58.git
cd moekyawaung-developer-portfolio-58

# Install dependencies
npm install

# Start the dev server
npm run dev
```

The app will be available at `http://localhost:5173`.

### Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the Vite dev server with HMR |
| `npm run build` | Type-check (`tsc -b`) and build for production |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint across the project |
