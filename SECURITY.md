# 🔐 Security Policy

## Supported Versions

This is a personal portfolio site under active development on the `main`
branch. Only the latest commit on `main` is supported with security fixes.

| Branch | Supported |
|---|---|
| `main` | ✅ |
| older tags / forks | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability (e.g. exposed secrets, XSS, dependency
vulnerabilities with real impact, or a build/deploy misconfiguration), please
**do not** open a public GitHub issue.

Instead, report it privately using one of the following:

- **GitHub Security Advisories** — use the [*Report a vulnerability*](../../security/advisories/new) button under this repository's **Security** tab (preferred).
- **Direct contact** — reach out via the GitHub profile [@Dev-moe-kyawaung](https://github.com/Dev-moe-kyawaung).

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce (proof-of-concept code or a minimal repro is appreciated)
- Any suggested remediation, if you have one

## What to Expect

- **Acknowledgment:** within a few days of your report.
- **Assessment:** the issue will be reviewed and a fix timeline communicated.
- **Disclosure:** once patched, the fix will be released and, where
  appropriate, credit given to the reporter (unless anonymity is requested).

## Scope

This site is a static frontend with no backend authentication, payment
processing, or user data storage. Reports about third-party services it links
to (e.g. Vercel's infrastructure) should be directed to those providers
directly.
